Right now, BRL-CAD is making extensive use of the libbv library.  We want to migrate
to using libbsg instead of libbv, but right now much of the core functionality still
lives in libbv.

We want to fold libbv into libbsg and remove libbv in favor of libbsg.  Functionality
in libbv should be moved to libbsg, and calling code should be updated accordingly.
bv_ and BV_ prefixes should be changed to bsg_ and BSG_.

Completion is defined as being able to remove libbv from the source tree and build
without loss of functionality or breakage.

IMPORTANT: There will be NO backwards compatibility maintained.  bv/ headers and libbv
will be FULLY ELIMINATED.  All callers will be updated to use bsg/ headers and the bsg_*
API.  bv/ headers exist only as TEMPORARY bridges during the migration — once all callers
have been updated the bridges will be deleted along with libbv.
