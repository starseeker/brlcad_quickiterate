BSG Raw Field Usage Inventory
==============================

Generated: Phase 0 of bsg_enhancement_plan.txt
Purpose:   Record direct uses of struct bv_scene_obj raw fields in src/ and
           include/ so that migration to BSG accessor APIs can be tracked.

This inventory was generated by searching the BRL-CAD source tree for
direct member accesses to the fields listed in bsg_enhancement_plan.txt
Phase 0 Task 1.  Files under src/libbsg/tests/ are excluded from the
counts below because they are expected to access fields directly as part
of regression testing.

Methodology: grep for both `->FIELD` and `.FIELD` patterns across all
.c and .cpp files under src/ and include/, excluding test directories.
Results are grouped by field and then by library directory.

Legend: counts are approximate line counts (one file may have multiple
hits per field).

Summary
-------
High-priority migration targets (most raw field use, highest architectural
impact):

  libdm/view.c           - s_flag, s_iflag, s_color, s_soldash, s_os, s_vlist,
                           s_v, s_mat, s_type_flags, s_force_draw, s_arrow
  libged/bsg_ged_draw.c  - s_flag, s_iflag, s_color, s_soldash, s_os,
                           s_color_rev, s_name, dp, s_i_data, s_vlist
  libged/draw.cpp        - s_name, dp, s_path, s_mat, s_vlist, s_os, s_soldash
  libged/dbi_state.cpp   - s_name, s_type_flags, s_i_data, s_color, s_flag,
                           s_os, s_mat, s_v, s_soldash
  libbv/util.cpp         - omnibus utility; touches nearly every field;
                           migrate as each concept gets its Phase 3+ API

Low-priority or intentional internal use:
  libbsg/* (internal implementation) - expected to access raw fields
  libdm/dm-gl_lod.cpp    - GL backend; encapsulated through bv_obj_backend in
                           most cases; remaining direct accesses are local
  libtclcad/view/*       - Tcl interop layer; migrate after BSG appearance

Known BSG accessor coverage already in place (Phase 1 + Phase 2):
  - s_type_flags: bsg_node_kind / bsg_node_has_kind / bsg_node_set_kind
  - s_name:       bsg_node_name / bsg_node_set_name
  - s_mat:        bsg_node_transform_get / bsg_node_transform_set
  - s_flag:       bsg_node_visible / bsg_node_set_visible
  - s_force_draw: bsg_node_force_draw / bsg_node_set_force_draw
  - children:     bsg_node_child_count / bsg_node_child / bsg_node_add_child /
                  bsg_node_remove_child
  - parent:       bsg_node_parent
  - bounds:       bsg_node_bounds_get / bsg_node_bounds_set
  - s_color_rev:  bsg_node_revision / bsg_node_bump_revision (Phase 2)
  - s_name/dp/s_path: bsg_identity_* (Phase 2)
